क्लाउड रीयल-टाइम डेटाबेस सेटअप (Firebase)

सभी मोबाइल और कंप्यूटर डिवाइसों पर वैश्विक रीयल-टाइम सिंक जोड़ें

त्रि-स्तरीय रीयल-टाइम सिंक प्रणाली:

1. Firebase Realtime Database (वैश्विक क्लाउड): नीचे अपना Firebase Database URL या JSON कॉन्फ़िग दर्ज करने पर सभी डिवाइसों के बीच वास्तविक समय (on('value') + Live Stream) में तुरंत डेटा सिंक होता है।

2. क्रॉस-टैब लाइव सिंक (BroadcastChannel): एक ही ब्राउज़र की सभी खुली विंडो और टैब्स में बिना किसी सेटअप के तुरंत अपडेट होता है।

3. ऑफ़लाइन कैश (LocalStorage): इंटरनेट बंद होने पर भी चयन सुरक्षित रहता है और कनेक्ट होते ही क्लाउड पर सिंक हो जाता है।

आप केवल अपना https://...firebaseio.com (या firebasedatabase.app) URL या पूरा Firebase JSON ऑब्जेक्ट पेस्ट कर सकते हैं।

      ".read": true,

    }
  }
}
